# Test Sonuçları

| Test Edilen | Beklenen Sonuç |
|---|---|
| Ürün başlığının tamamını arama | Aranan başlıkla eşleşen ürün gösterilir. |
| Ürün başlığının bir bölümünü arama | Başlığında aranan bölüm bulunan ürün gösterilir. |
| Aynı kelimeyi büyük ve küçük harflerle arama | Harf büyüklüğü fark etmez; aynı eşleşen ürünler gösterilir. |
| Ürün başlığında bulunmayan bir ifade arama | Eşleşen ürün bulunmadığı belirtilir. |
| Tab tuşuyla kontrol etme | Odak arama alanına ve arama düğmesine sırayla ilerler; odak görünür olur. |
